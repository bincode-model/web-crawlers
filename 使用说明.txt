Web Crawlers 中文使用说明

项目位置：你下载或克隆的 web-crawlers 文件夹
原项目：https://github.com/cyohei9907/web-crawlers
基于的上游版本：2a15a2d7bc912abf095beca5bf4b429f4d90df32

这是一个“蜘蛛在网页文字上爬行”的动画项目。蜘蛛踩到的字会出现高亮、变形和蛛丝效果。项目包含独立演示网页和 Chrome 扩展，不采集、记录或导出网站数据。

一、先玩演示版

Mac 启动方式：
1. 在终端进入项目文件夹，运行：zsh ./启动演示.command。终端窗口会显示本地网址。
2. 在浏览器打开 http://127.0.0.1:5173。
3. 使用期间保留终端窗口；需要停止服务，在终端按 Control+C。

也可以在终端进入项目文件夹后手动输入（Windows 可使用 python）：
python3 -m http.server 5173 --bind 127.0.0.1

演示版操作：
移动鼠标：蜘蛛追随鼠标。
点击页面：让蜘蛛往点击的位置走。
空格：暂停 / 继续。
F：打开 / 关闭镜头跟随（页面会随着蜘蛛滚动）。
刷新页面：重新开始。

先点一下页面再按键；地址栏获得焦点时，按键不会控制蜘蛛。
页面上的英文百科内容和参考文献是程序生成的演示文字。
演示版和扩展均不需要 npm install，也不需要构建。

如果启动时报“Address already in use”：端口 5173 已经被占用。演示已经在运行时，直接打开上述网址即可，不必重复启动。若这个网址显示其他项目，改用以下命令并打开 http://127.0.0.1:5174：
python3 -m http.server 5174 --bind 127.0.0.1

二、让蜘蛛出现在其他网页：安装 Chrome 扩展

要求：Chrome 116 或更新版本。

1. 在 Chrome 地址栏输入 chrome://extensions。
2. 打开右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择下面这个目录（不要选择项目根目录）：
   项目文件夹中的 extension/src
   该目录应该包含 manifest.json。Mac 文件选择窗口可按 Command+Shift+G，输入这个目录在你电脑上的完整路径，按回车进入后选择。
5. 打开一个有文字的普通网页。
6. 点 Chrome 工具栏的拼图图标，找到 Web Crawlers；可点固定按钮将它放到工具栏。
7. 点击 Web Crawlers 图标，再点“放出蜘蛛”（Release the spider）。
8. 要停止，点“收回蜘蛛”（Recall the spider），或刷新网页。

扩展的默认快捷键：Alt+Shift+S，Mac 对应 Option+Shift+S。
若快捷键未设置或发生冲突，到 chrome://extensions/shortcuts 分配，以扩展弹窗实际显示为准。

扩展设置：
自动阅读：默认关闭；开启后页面缓慢向下滚动，没有朗读声音。
大小：S / M / L，默认 M。
特效：平静 / 普通 / 狂野，默认普通。
修改设置会应用到当前蜘蛛并保存。

注意区分：空格、F、点击指挥是独立演示版的操作。Chrome 扩展不提供这些控制；扩展可以移动鼠标引导蜘蛛。

三、常见问题

“选文件夹后加载失败”
选 extension/src，里面应该有 manifest.json。

“装好了却没有蜘蛛”
请先打开普通网页，再点“放出蜘蛛”。Chrome 设置页、扩展管理页、网上应用店和内置 PDF 等受保护页面不能运行。图片或视频为主的页面文字少，效果也会较弱。

“刷新后蜘蛛消失”
这是正常行为；刷新或跳转后需重新放出蜘蛛。

“想恢复页面或卸载”
点击“收回蜘蛛”或刷新即可清除效果。扩展不会永久改写网页文字。卸载时在 chrome://extensions 找到 Web Crawlers 点“移除”，随后刷新之前运行过蜘蛛的页面。

四、安装范围与设置保存

扩展权限为 activeTab、scripting、storage：用户点击后临时访问当前页、注入本地动画代码、保存设置。项目隐私说明声明不收集或上传页面内容；设置使用 Chrome 同步存储，开启 Chrome 同步时可能在同账号浏览器之间同步。

这份说明依据原项目 README 和扩展源码整理。扩展权限和行为详见 PRIVACY.md。

js/crawler.js：蜘蛛运动；顶部 T 对象包含速度等参数。
